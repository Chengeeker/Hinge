此目录是 Hinge 的 Flutter 客户端工程，包含 Android 客户端与 Windows 桌面宿主，不是独立的 Flutter 示例项目。

- 用户安装、功能和 Cloud Relay 指引见[仓库根目录 README](../README.md)。
- Android 本地开发与测试命令也见[根 README 的本地开发章节](../README.md#本地开发)。
- 当前发行版与下载见 [Hinge v1.4.5](https://github.com/Chengeeker/Hinge/releases/tag/v1.4.5)，历史版本见[变更日志](../CHANGELOG.md)。
