# Hinge v1.4.15

本次更新以最后一个公开发行版 v1.4.14 为基线。Windows 桌面仍使用现有 Windows App SDK，界面按 Material 3 进行统一和修复；本次没有替换底层窗口框架。

## Windows

- 完成主要页面的 Material 3 视觉统一：设置分组与页面对齐、首页设备和传输记录、文件管理、笔记、待办、日历、相册、通知、个性化、Cloud Relay 与 WebDAV。
- 调整窗口标题栏与侧边导航，修复窗口控制按钮悬停、折叠留白和窗口尺寸变化下的页面布局。
- 重做日历月视图的日期状态、事件展示与选择交互，修复新建日程入口及日期跳转弹窗；保留现有日历同步协议和事件处理。
- 个性化新增自定义字体导入，支持字体文件和 ZIP 字体包；可按字体系列与字重选择、移除导入字体，并全局应用正文文字。
- 支持已知手机品牌 Logo；无法识别时显示 Android 默认图标，未连接状态也显示默认图标。
- 未连接手机时禁用首页发送操作并提示先连接设备；修复设备 Logo、传输记录间距、记录可视区域和文件网格自适应。
- 修复 Android ADB 配对身份校验与自动恢复，并新增 Android 原生无线 ADB 剪贴板桥接；修正文件/相册请求加载停滞问题。
- 安装器默认识别既有安装目录，避免把项目构建目录误当作安装位置。

## Android

- 新增无线 ADB 剪贴板桥接和连接恢复相关配合逻辑。
- 版本：`1.4.15+120`，仅提供 `arm64-v8a` APK。

## Windows 下载

- `Hinge-Setup.exe`：自包含安装器，可选择安装目录。
- `Hinge-Windows.zip`：便携版。
- Windows 文件版本：`1.4.15.0`。

## 验收说明

每项 UI 修复的截图条件、功能回归和边界见 `docs/` 内的专项验收报告。报告区分了实际运行截图、构建结果和未完成的真机/DPI 覆盖；本发行说明不把未覆盖条件表述为已验收。

> Windows Hinge-Setup.exe 未使用 Authenticode 代码签名；首次运行时 Windows 可能显示来源提示。
