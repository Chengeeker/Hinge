# Hinge v2.0.0 更新日志

本说明以 Windows 旧版界面 v1.4.14 为对照基线，汇总随后完成的 Material 3 界面升级、跨端能力改进和 v2.0.0 修复。Windows 桌面客户端继续使用现有应用与业务实现；这次没有重写传输协议。

## Windows 界面与交互

- 将 Material 3 视觉规范应用到设置、首页、文件管理、笔记、待办、日历、相册、通知、个性化、Cloud Relay 和 WebDAV 页面，统一分组层级、文字、表面颜色、控件状态和布局间距。
- 调整侧边导航、窗口标题栏和主内容区域；修复导航收起后的空白占位、窗口控制按钮悬停底色异常，并改善不同窗口尺寸下的布局。
- 关于应用调整为独立页面，保留版本号、应用图标、功能介绍与 GitHub 开源链接等信息。
- 统一设置子页面的内容宽度和起始位置；传输设置按功能分组，修正输入框文字垂直位置以及 Android 无线 ADB 区域的宽度和排列。
- 重整日历月视图的日期状态和日程展示，区分今天与选中日期，改善日程颜色、全天事件和溢出显示；修复新建日程与跳转日期的操作入口。保留原有日历同步和事件处理。
- 个性化支持导入字体文件或 ZIP 字体包；按字体系列和字重区分样式，避免重复导入造成重复项，支持删除导入字体，并将选择应用到正文文字。
- 设备识别到品牌时显示对应 Logo；未知品牌或未连接时显示 Android 默认图标。修复首页设备行 Logo 与文字间距，以及传输记录 Logo、记录可视区域和文件宫格列数随窗口变化的问题。
- 手机未连接时禁用首页发送文件并提示先连接；修正首页设备、传输记录、文件管理和通知页面的布局问题及可点击区域光标提示。
- 安装器默认使用已有安装目录，避免误把项目构建目录作为安装位置。

## Android 与跨端连接

- 增加 Android 原生无线 ADB 剪贴板桥接；配对身份校验和已配对设备的自动连接恢复得到修正。剪贴板桥接通过无线 ADB 工作，不承载文件传输。
- 修正部分文件和相册请求加载停滞的问题。
- v2.0.0 修复设备页未跟踪 Windows 主动发起或恢复的新会话：新建及已有会话现在会一并更新 Android 侧的连接状态和对端信息。
- 跨端传输协议版本保持 0.1；本次没有协议破坏性变更。

## 验证结果与限制

- Android Flutter 测试 77/77 通过；设备页面定向测试 12/12 通过。新回归测试覆盖应用启动后创建的出站会话。
- Windows Release 安装器与便携包构建完成；ZIP 的 810 个条目均可读取，包内 Hinge.dll 与 Release 输出一致。
- Android APK 包名、版本、架构和 v2/v3 签名已核验；签名证书与 v1.4.15 回退 APK 相同。
- Windows 最近一次完整自动化测试为 v1.4.15 基线的 198/198 通过；v2.0.0 的 Windows 代码没有功能逻辑变更，仅更新版本信息，因此本次未单独重跑 Windows 测试。
- 没有在真实 Android 手机与 Windows 电脑之间现场验证本次连接状态修复。自动化回归测试不等于真机验收。
- Windows 安装器外层 Authenticode 未签名，首次运行时 Windows 可能显示来源提示。
