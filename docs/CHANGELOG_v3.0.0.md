# Hinge v3.0.0 更新日志

发布日期为 2026 年 11 月 7 日。本版对照上一正式发行版 [v2.2.0](https://github.com/Chengeeker/Hinge/releases/tag/v2.2.0)，汇总此后的新增能力、界面更新和既有功能修复。

Hinge 3.0.0 新增手机查看并操控 Windows 桌面、手机触控板、游戏按键映射及布局管理，Android 客户端切换至 Kotlin 与 Jetpack Compose。

## 新增功能

### 手机查看并控制 Windows 桌面

- 支持在同一局域网内，将 Windows 桌面显示到 Android 手机，并通过手机操作电脑。
- 支持横屏全屏显示。两侧工具栏提供鼠标、键盘和常用操作，画面居中；操作面板采用适合横屏的紧凑字号和控件尺寸。
- 支持「屏幕触控」和「鼠标指针」两种操作方式，可按使用习惯切换。提供轻点、双击、右键、滚动、长按后拖拽，以及画面缩放和平移。
- 支持显示鼠标按键、调节灵敏度和切换仅观看模式。打开工具面板、退出控制或连接失效时释放按键，减少残留按下状态。
- 支持向电脑发送文本，提供 Esc、Tab、方向键、F1–F12，以及复制、粘贴、撤销等快捷操作。
- 新增显示桌面、切换窗口、打开资源管理器、任务管理器和开始菜单等系统快捷操作；支持经过确认后请求锁定、重启和关闭电脑。
- Windows 提供共享显示器选择、帧率上限、最长边和码率设置。桌面视频使用独立的 H.264 媒体通道，优先使用可用的硬件编码器；Android 使用原生解码与显示路径。
- 首次桌面连接通过双端核对身份码建立信任，桌面视频与输入通过 TLS 通道传输。设置页分别展示共享和控制开关、运行状态，方便随时停止。
- 可选显示实际视频输出、解码和帧间隔统计，便于判断当前表现。实际帧率和延迟受画面内容、编码器、手机解码与无线环境影响。

### 手机触控板

- 支持把 Android 手机作为 Windows 电脑的触控板使用，单指滑动移动鼠标、轻点左键，双指轻点右键、双指滑动滚动。
- 支持横屏布局，左侧轻点对应鼠标左键，右侧轻点对应鼠标右键；说明区与主要操作区分开布置。
- 支持拖拽手势与文本输入。竖屏触控板提供游戏模式入口，可直接进入全屏操控布局。
- 鼠标与视角灵敏度默认值为 3，可在 1.5–5 范围调整。

### 游戏模式与按键映射

- 支持在触控板中使用全屏游戏模式，也可在电脑桌面的操作面板中开启「按键映射」。
- 支持拖动式 WASD 轮盘、键盘按键、鼠标按键和多指组合操作，提供触控反馈。
- 支持按住映射鼠标键后滑动拖拽，也可用一指按住鼠标键、另一指移动。普通鼠标操作与游戏视角可分别选择。
- 桌面映射按键覆盖整个可用全屏区域，可利用画面两侧的黑边；映射期间隐藏两侧工具栏，通过返回或退出按钮结束映射。
- 提供游戏基础布局和桌面精简布局。支持多套预设的新建、复制、重命名、切换和删除。
- 支持自定义按键位置、大小、比例、形状、圆角、显示文字、图片和对应电脑按键。布局以相对坐标保存，适配不同屏幕尺寸。
- 手机布局编辑采用画布与工具区分离的方式，支持选择、拖动、缩放查看、属性编辑和位置微调。
- Windows 新增布局编辑入口，支持读取手机预设，选中后拖动或拉伸，提供对齐辅助线与吸附，保存后同步至手机。
- 支持预设文件导入和导出，方便更换设备时迁移，也可将方案分享给其他用户。

### 无线 ADB 指令与托盘传输

- Windows 无线 ADB 板块新增指令输入区，可向当前已配对的手机运行单次 ADB 指令，查看实时输出并停止运行。
- 指令运行具有时间和输出长度限制，便于处理误启动或持续输出的任务。
- Windows 托盘菜单新增「传输文件」入口，可恢复主窗口并选择文件发送。未连接手机时给出连接提示。

### 配对码更新后重新验证

- 双端支持在首次设置、更换或清除本机配对码后结束现有局域网连接，正在握手的旧连接也会失效。
- 启用或更换配对码后，重新连接需通过当前配对码验证。保存相同配对码时，当前连接继续使用。
- Windows 手动连接需要配对码的设备时重新显示输入框，方便使用更新后的配对码。
- 设置界面说明改码会断开连接，便于在文件传输或远控前安排操作。

## 界面与使用体验

### Android 原生界面

- Android 客户端由 Flutter 切换为 Kotlin 与 Jetpack Compose，沿用应用包名与正式签名，支持覆盖安装。
- 更新首页、工作区、设置和个性化页面的 Material 3 排版、表面色、文字层级与分组方式。
- 更新液态玻璃悬浮底栏的选中背景移动、水珠形变、模糊与折射表现，并保留相关触感设置。
- 移除普通按钮和设置项的点击、长按水波纹；液态玻璃底栏保留自身的水珠交互。
- 设置分组标题与内容图标的左侧对齐，功能之间使用卡片和留白分组。

### Windows Material 3 界面

- 调整浅色、深色模式的窗口背景、内容卡片、选择器和输入框色彩，统一公共组件的圆角。
- 调整侧边栏图标、文字与选中样式，以及首页和设置页的层级、间距与对齐。
- 优化选择控件与弹窗的文字显示及交互反馈，日期选择区使用更协调的比例。
- 系统托盘菜单使用固定白色背景、圆角、紧凑留白和悬停反馈，宽度根据菜单文字计算。
- 关于应用更新 Android 技术说明，与 Compose 客户端保持一致。

### 投屏与远控入口

- 双端统一使用「投屏与远控」入口，再分别进入「手机投屏到电脑」与「手机控制电脑」设置。
- 两个方向各自使用完整子页，开关、状态和参数集中展示。
- 简化 Android 使用说明，突出开关和必要的连接条件。Windows 画质参数采用滑块调整。
- Windows 控制 Android 继续复用内置投屏组件与无线 ADB，支持上一版已有的 H.264、H.265、AV1 和画质设置。

## 既有功能修复与改进

- 修复设备列表手动断开后，另一端自动拨入可能使同一设备立即连回的问题；保留用户主动重新连接的路径。
- 修复 Android 前后台切换后可能保留失效会话、重复显示同一台电脑的问题。同名但设备 ID 不同的设备分别显示。
- 改进双端连接状态恢复与事件处理，减少实际会话和界面连接状态不同步的情况。
- Windows 相册集和相册内照片列表按窗口宽度自动调整列数，优化视图、排序和刷新控件的垂直对齐。
- 改进 Windows 打开手机相册原图的入口、读取、缓存和错误提示，支持照片卡片点击、键盘和右键打开，交给系统关联的图片应用处理。
- Windows 覆盖安装复用已注册且内容一致的资源管理器右键集成，减少重复注册。
- 双端在 Cloud Relay 上传前检查分块数量上限，对超限文件提前提示，避免无效的后续处理。

## 升级与使用说明

- 推荐双端一起更新，以使用新的远控、按键预设同步及连接控制行为。
- Android 沿用 `com.hinge.office` 和原签名，可直接覆盖安装。升级前如有重要资料，建议先做好备份。
- 手机控制电脑需在 Windows 设置中开启桌面共享和控制权限；电脑控制手机需在 Android 系统中开启无线调试并完成 ADB 配对。
- 双向实时远控目前面向局域网。Cloud Relay 继续提供异步文件中转；公网实时远控、电脑音频回传等能力尚未提供。
- H.264 用于本版 Windows 桌面发送到手机的媒体链路；H.265、AV1 选项属于电脑查看手机画面的投屏链路。
- 更改配对码会中断当前局域网传输和远控，需重新建立连接。清除配对码后，后续连接按无配对码设置处理。
