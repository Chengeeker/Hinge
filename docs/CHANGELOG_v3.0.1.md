# Hinge 3.0.1 更新日志

## Windows 关机修复

- 修复 Windows 关机期间，无线 ADB 后台重连仍可能启动 `adb.exe`，触发 `0xc0000142` 初始化失败弹窗的问题。
- Hinge 收到 Windows 会话结束请求后暂停 ADB 和投屏启动。如果取消关机，自动重连恢复。

## Windows 文件管理界面修复

- 手机和 WebDAV 来源标签采用 Material 3 选中态，适配浅色和深色主题。
- 统一文件操作确认框的按钮尺寸和配色，删除操作默认聚焦取消。

## Windows 无线 ADB 扫码配对

- 在「设置 → 传输与连接 → 高级诊断 → Android 无线 ADB」新增扫码配对入口。
- 在手机系统的「无线调试」中选择使用二维码配对，扫描电脑显示的二维码。配对完成后 Hinge 会自动尝试连接，六位配对码仍可使用。

[Windows 安装包对应的源码提交](https://github.com/Chengeeker/Hinge/commit/90c93e75cd079d29876011e6d4a9d64b7691d099)。

本版提供 Windows x64 安装器与 Android arm64-v8a APK，可覆盖安装。上一版 Windows 便携包仍可从 [v3.0.0 发行页](https://github.com/Chengeeker/Hinge/releases/tag/v3.0.0) 下载。

ADB 与投屏相关的 91 项自动化测试以及本机模拟配对已通过。实际手机扫码、自动连接及关机表现待设备验证。

安装器 SHA-256 `3c3f8e7b7abdb9638ef50c9375d97bf6c83a17233a2e7a2dc68293861f3cb518`

## Android 3.0.1

- 新增「设置 → 手机服务 → 无线 ADB」独立入口，提供扫码配对和配对码配对的系统跳转与操作提示。
- 新增独立「剪贴板同步」设置入口。开关可以提前开启并保存偏好，连接无线 ADB 且电脑端允许同步后生效。
- 开启剪贴板同步后显示简短连接说明，并可直接前往无线 ADB 设置；关闭后暂停新文字的双向同步，保留已有配对，不影响投屏与文件传输。
- 设置页沿用 Material 3 排版、浅深色和大字号适配，点击反馈遵循应用触感开关，避免同一次操作重复震动。
- Android 版本名更新为 **3.0.1**，内部构建号 **195**，沿用原包名与签名，仅提供 **arm64-v8a** 安装包。

### 使用说明

- 系统是否允许直达无线调试或扫码页取决于手机系统。部分机型仍需在开发者选项中手动进入「无线调试」，本版不保证所有机型一键直达。
- 更新后建议在电脑端重连一次无线 ADB，使剪贴板桥加载新版设置开关。
- Android 相关的 21 项自动化测试通过，Release 构建、签名、ARM64、ZIP 完整性和 16 KiB 对齐校验通过；真实扫码、双向剪贴板和物理振感仍需设备验证。
