# Hinge 3.0.2

## 设备连接与名称

- 修复换机后旧设备地址重连可能干扰新设备会话的问题。设备记录按 ID 隔离，重用 IP 不再合并身份或继承信任。
- 双端直连、反向连接和后台重连增加目标设备身份校验。建议电脑和手机一起更新。
- Android 扩展跨品牌市场名读取，增加约 5.3 万条离线设备记录，按品牌、型号与设备代号匹配。歧义型号继续回退，识别无需联网。

## Windows 界面

- 文件管理的设备标签保持单行并按名称伸展，超长名称省略且保留完整提示。
- 清空传输记录统一为 M3 危险操作确认框，进行中的任务继续保留。

## 安装包与验证

- Android 3.0.2，内部构建号 198，仅 arm64-v8a，沿用原包名及签名。
- Windows 3.0.2，x64 安装器。
- 已通过针对性身份隔离、多设备及名称匹配测试，双端 Release 构建及产物检查。
- 尚未完成各品牌真机、换机连续连接及新版 Windows 界面的实机验收。设备目录有遗漏，无法保证所有机型都能取得市场名。
