## 真机步骤与预期

1. **电脑入口**：设置 → 投屏与远控 → 手机远控电脑。开启“允许 Android 手机控制此电脑”和“允许手机查看电脑”，确认显示器选择，先用 60 FPS / 1920 / 8 Mbps 保存。新安装默认关闭；开启后用户偏好应跨应用重启和覆盖升级保留。进程退出时服务停止，下次启动按保存的偏好恢复。
2. **手机入口**：设置 → 投屏与远控 → 手机控制电脑 → 已连接电脑 → 电脑桌面。首次连接两端核对同一身份码后分别允许；无需复制旧触控板加密密钥。未确认前不得出现电脑画面或注入操作。已确认设备正常重连不应再次核对。

   若两端报 EOF，请先覆盖更新本次 Android 修复包；旧版本 Keystore 身份可能未授权 TLS 原始签名。新版本会在连接前预检，错误也会注明阶段。若此前已保存过不兼容旧手机身份，电脑明确提示身份变化时，使用本页“清除手机桌面身份”后再开启共享并核对，不要删除应用数据或关闭证书校验。新版电脑日志在 `%LOCALAPPDATA%\Hinge\lifecycle.log`，查找 `desktop-connection-error`。
3. **基本操作**：操作菜单可选直接触控或鼠标指针；直接触控点哪里操作哪里，按住滑动拖拽；指针模式单指滑动移动鼠标，轻点左键，长按或双击按住拖拽。两种模式双指轻点右键、平行滑动滚动、捏合缩放；拖拽有轻触反馈及左键按住提示，菜单可锁定左键再滑动并手动松开。仅观看时点击、键盘和游戏入口不得发送控制。旧Windows未声明absoluteMouse时不能启用直接触控。横屏工具栏左右键、文本输入可用。移过文本/链接/窗口边缘，检查文本光标、手形和缩放箭头及热点是否正确，屏边不能出现双光标；再用手机远控滑动让Windows应用隐藏系统光标，确认手机画面仍叠加可见箭头。拖动窗口/滚动网页后离开页面或切后台，不得留下按住的鼠标。
4. **画面操作**：普通模式双指平行移动滚动、捏合缩放；本次手势锁定后不得同时发送另一用途事件。缩放快速经过 1 倍时画面不能闪烁。切换缩放/平移模式后单指平移、双指缩放仅操作手机画面，不能同时移动电脑鼠标；切回操作模式恢复控制，放大后的点击仍正确落在电脑对应位置，黑边点击无效。横竖屏切换应保留会话，不能要求反复配对。
5. **显示器**：所选屏幕外的鼠标，首次远程移动/点击应回到所选屏幕；移动到边缘不能点到另一屏。负坐标、竖屏和不同 DPI 仍需实际多屏验收。断开所选显示器/改变其布局后应停止输入并提示重连，不能自动共享另一屏。
6. **连续运动**：持续滚动同一网页或拖动同一窗口，与电脑画面对比卡顿、延迟和拖尾。记录电脑实际编码器、手机实际解码器、视频输出 FPS、纹理取帧 FPS、两种最大间隔和待解码数。2.4.3迁移SurfaceProducer后，纹理取帧统计不可用，不再显示为实际采样FPS。静止时 FPS 下降、间隔变长属于正常现象。“界面重建 P95”不包含所有纹理快速重绘，不是端到端延迟，也不能用来断言视频掉帧。
7. **恢复与停止**：短暂网络中断应有限重试；连续失败三次后保留提示。切后台断流，返回可恢复此前观看，包括等待首帧时切后台。快速切换连接时，旧停止回调不能结束新连接。身份验证后仍须等解码器向Surface输出首帧才开放操作；SurfaceProducer无公开取帧回调，不能据此证明Flutter已呈现。8秒未输出首帧应报错并断开，不能仅靠保活一直黑屏。身份拒绝不自动重试或清除身份。关闭电脑远控/共享后，手机输入必须停止且按键释放。
8. **桌面游戏覆盖**：从桌面页横屏或竖屏的“游戏模式”进入，画面应铺满背景，原预设、拖动摇杆、多指按钮、图片/文字按键及布局编辑仍可用。退出按钮/系统返回仅退出覆盖，视频不重连；按住按键退出不能卡键。电脑端需更新并声明相对鼠标支持，否则入口禁用。游戏视角发送相对位移，目标游戏需在前台接收鼠标；它不适用普通桌面屏边限制，游戏是否捕获鼠标及接受 SendInput 需实际验收。不要绕过游戏或 Windows 的权限限制。
9. **横屏沉浸桌面**：电脑桌面横屏时默认显示沉浸布局，隐藏系统栏并去掉顶部横排按钮及视频卡片边距。左右控制栏等宽，视频区域居中；按两侧较大的安全区统一预留栏位，避免单侧屏幕缺口把视频推离中心。左栏提供左键、右键、按住/松开拖拽和缩放快捷操作，右栏保留操作、键盘、显示桌面、所有窗口和退出全屏。按钮保持至少64dp触控高度，短屏时两侧可分别滚动；操作菜单可滚动并提供默认关闭的性能信息开关。退出全屏/系统返回切到竖屏；从游戏覆盖返回仍保持横屏沉浸和同一视频连接。按比例完整显示桌面，禁止拉伸或裁掉边缘。
10. **更新后设置保留**：在本修复版上分别开启/关闭桌面共享后重启 Hinge，确认两种选择都保持；开启时再做一次覆盖升级，确认共享开关和帧率/分辨率/码率/显示器选择保留。此前版本从未保存过共享开关，所以升级到本修复版后需重新选择一次，之后才会记住。

## 已有离线证据及待完成项

协议/TLS/输入所有权、边界与旋转映射、Flutter 手势/重连、解码进度与裁剪状态已有定向测试。NVIDIA H.264 MFT 和 GPU 转换已有电脑端合成验证；包签名、ABI、对齐和载荷已核验，具体日志和校验值见 `DESKTOP_REMOTE_IMPLEMENTATION.md`。

物理多屏/旋转、厂商 MediaCodec、实际显示节拍、无线端到端延迟和交互手感均未真机验收。已接入系统光标图像与热点；系统光标隐藏时按当前鼠标坐标回退绘制轻量箭头，即使DXGI报告光标嵌入画面也会显示；系统光标可见且已嵌入画面时不重复绘制。动画光标目前只取首帧。此补修尚未在用户设备上验证，需覆盖更新Windows后确认手机触控期间光标仍可见。游戏覆盖已接入同一视频与 TLS 输入会话，已有模拟回归，但真实游戏视角/触控/注入兼容性尚未验收。不能将当前候选描述为已经达到 UU 的实际体验，或将全部待办标为完成。

Windows层级验收：设置首页 → 投屏与远控，仅显示两个并列入口；“手机投屏到电脑”和“手机远控电脑”各自进入完整子页，两个子页返回统一页，统一页返回设置。统一页不得混放任一方向的完整参数。
