# 手机电脑桌面操作面板

从 2.8.0 开始，手机电脑桌面的工具按用途分组。横屏从右侧展开面板，竖屏从底部展开；视频保留原来的 Texture 和会话，工具面板叠放在画面上，不改变编码或重启连接。

| 分组 | 已支持的操作 |
| --- | --- |
| 操作 | 退出远控、全屏、仅观看、启用按键映射、屏幕触控/鼠标指针、鼠标按键显示、灵敏度 |
| 显示 | 当前视频尺寸、缩放/平移、适应屏幕、150%/200%视图缩放、性能信息 |
| 键盘 | 文本输入、Esc/Tab/Enter/退格/Delete/空格/方向键/F1–F12、复制/粘贴/剪切/全选/撤销/重做 |
| 系统快捷操作 | 显示桌面、所有窗口、切换窗口、资源管理器、任务管理器、开始菜单、锁定/重启/关机 |

全屏继续使用左右等宽工具栏，隐藏鼠标按键后也保留画面居中。仅观看会阻止鼠标、键盘、系统快捷键和电源请求，仍可查看画面和调整本地视图；打开面板会先释放进行中的拖拽。组合键按顺序按下、逆序释放，不留下粘滞修饰键。文本发送到电脑当前焦点，不是剪贴板同步。

视图缩放以适应屏幕的大小为基准，保持宽高比；不修改电脑显示分辨率或系统缩放。视频帧率、编码码率和共享显示器仍在电脑端远控设置中调整。声音、小窗、原生触屏注入、外设和安全桌面操作尚未接入。

## 横屏紧凑布局

Android 2.8.1 将横屏工具面板调整为紧凑密度：较小的页标题/图标、三等分的单行快捷操作、紧凑设置行和单行灵敏度。显示、键盘及系统操作子页共用局部主题，系统大字体仍生效，短屏内容可滚动。竖屏及左右工具栏保持原样，Windows 2.8.0 可继续使用。

## 按键映射

在“电脑桌面 → 操作”打开“启用按键映射”，下方出现“切换操控方案”“编辑当前方案”“其他设置”。方案列表支持选择、复制、重命名、删除和新建；编辑沿用现有控件位置、大小、形状、文字/图片及电脑按键映射。其他设置提供触控反馈、鼠标灵敏度和按键不透明度，横屏面板采用紧凑字号与触控范围，不显示功能间的亮色分割线。

Android 2.10.0 默认使用“桌面精简布局”：左侧 Esc、Tab、Ctrl、鼠标左键，右侧退格、Enter、Alt、鼠标右键。中央区域使用操作面板中所选的鼠标模式；Ctrl/Alt和鼠标键可持续按住并与其他手指配合。默认按键背景半透明，不再显示大地图、轮盘和常驻中间提示。原游戏和自定义方案保留，仍可从方案列表选择；独立触控板游戏的默认布局不变。

桌面单独记住所选方案，不改变触控板所选的游戏方案。控件数据仍共用原有版本1预设文件，已有 Windows 编辑器可以读写；桌面选择存于手机本机偏好，不改变旧版 Windows 的数据协议。精简布局在预设未满32套时补入内存，选择保存或编辑保存后写入共享文件；读取不自动覆盖旧文件，也不删除已有方案腾位置。

启用进入横屏；关闭开关或普通系统返回只结束映射，保留桌面会话。映射状态保留在本桌面页中，开关不另建视频连接；编辑返回仍使用放弃修改确认。打开任一工具面板会暂停映射并释放按键，关闭后恢复；普通映射只拦截实际按钮，空白区沿用桌面手势，游戏视角才接管画面输入。仅观看、连接中断或能力撤销会关闭映射。

电脑需声明相对鼠标/游戏按键能力；Windows 2.8.0 已支持，无需更新。旧电脑不声明时禁用开关。映射发送键盘和鼠标，不等于原生多点触屏；目标程序需有焦点并接受当前权限的模拟输入，实际游戏兼容性与手感仍待设备验收。

## 映射下的鼠标操作（Android 2.10.1）

按键层和鼠标模式独立：开启映射不会强制变成游戏相对移动，左侧鼠标工具仍可用。选择“屏幕触控”时点按画面定位并点击、滑动仅移动指针；选择“鼠标指针”时滑动从当前光标位置移动、轻点左键、双指轻点右键、双指滑动滚动或捏合缩放。两种模式均需停住长按后再移动才开始拖拽，抬手松开。双指滚动/缩放沿用既有意图锁，不会同时发出拖拽。两种模式分工参考[Moonlight维护者的手势说明](https://github.com/moonlight-stream/moonlight-docs/wiki/Setup-Guide#keyboardmousegamepad-input-options)，不是搬用其实现代码。

映射的鼠标左、右、中键都支持按住后同一手指滑动，指针从当前位置移动，不跳到按钮或另一根手指的位置；也可一指按住鼠标键，另一指在画面滑动拖拽。修饰键与画面点击可以配合。画面拖拽和映射按键共用鼠标按键所有权：最后一个持有者松开时才释放；按钮先松开、画面手指后松开也不会补发一次假点击。灵敏度在两处设置同步作用于同一控制状态，不改变现有默认3.0。

仅在锁定光标、需要旋转视角的3D游戏中开启“游戏视角”。此模式滑动发送游戏相对输入，轻点空白画面不点击；第二根手指落下不会立刻按左键，双指移动达到阈值才开始左键拖拽。地图、菜单或办公场景关闭游戏视角，恢复触控或指针模式。独立触控板的游戏路线仍保留原WASD、相对视角和双指拖拽，鼠标映射键补上同指拖拽。

视频Texture、缩放坐标与会话仍由原DesktopVideoView管理；切换映射或鼠标模式不会重连视频。编辑层和模态面板阻止画面输入，暂停、旋转、断线和权限撤销仍释放按键。未新增驱动或原生触屏注入，真实鼠标/游戏手感仍待用户实机验收。

## 普通移动与拖拽（Android 2.10.2）

移除侧栏“按住拖拽/松开左键”按钮和操作面板“按住左键拖拽”开关，不再让用户进入持续锁定左键的模式。普通单指滑动只移动鼠标，不会选择文本或拉出选区；点击后紧接滑动也不再自动按住左键。连续轻点继续发送普通点击，由电脑识别双击。

需要拖拽时，手指在画面中停住约半秒，再移动超过小幅防抖距离，才会按下左键并给轻触反馈；抬手、取消、切换模式或切后台即释放。本轮保留450ms/8dp的原有阈值，不再在第二次触点按下或单纯计时结束时直接发送左键。映射的鼠标键仍可物理按住并同指或跨指拖拽，游戏视角和独立触控板原有手势保留。

未配置输入方式的新设备默认鼠标指针，已保存的触控/指针偏好保留。直接触控仍使用画面坐标，指针模式仍从当前光标位置移动，二者的普通滑动都不应形成选区。不会修改视频会话、原预设或系统鼠标配置。

## 视频启动与恢复

Android 2.10.0 修正视频组件部分创建失败后的清理，停止会话在解码器和 Surface 释放后才回复。新会话遇到旧资源尚未释放时走现有的三次有界恢复，不同时堆叠解码器；Surface 创建异常提供阶段与异常类型，不再只显示空的 PlatformException。身份、权限和未知启动失败不会因此无限重试。保留 SurfaceProducer 渲染路径。

图示偶发黑屏还需要实机复验：离线检查确认的是资源释放顺序、恢复次数及错误处理，不能由 null 提示推断唯一 GPU/厂商解码根因，也不能据此宣称已达到 UU 的实际延迟和流畅度。

## 系统操作与兼容性

锁定、重启和关机都需要手机二次确认，仅通过已有双向 TLS 桌面会话发送。服务端检查当前控制 lease、连接设备信任和固定动作/16 字节载荷；普通文件连接、独立触控板和失效控制会话不能执行这些操作。握手新增可选 `systemActions` 能力，旧电脑不声明时手机不显示电源组，旧手机继续按原有协议工作。

“已发送请求”表示请求已进入控制发送队列，不保证 Windows 已完成操作。锁定后可能需要在电脑上解锁；关机/重启后需要电脑重新启动才能连接。系统仍可以因账户权限或未保存应用拒绝请求。

Windows 使用固定绝对路径的 `shutdown.exe /s /t 0` 或 `/r /t 0`，不使用 shell、不强制关闭应用、不提权。采用零超时是因为[官方 shutdown 文档](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/shutdown)说明正数超时会隐含强制关闭参数。锁定使用系统 [LockWorkStation](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-lockworkstation)，不模拟安全注意序列。

## 验证范围

自动回归使用 Mock 输入/系统回调、电脑本机 TLS 回环和 Flutter 模拟平台通道；覆盖权限撤销、非法请求、旧端能力缺省、仅观看、面板/全屏会话保持、缩放和触控板原有游戏入口。没有实际锁屏、关机、重启或操作手机。真机上的显示流畅度、缩放黑块、网络恢复和系统动作执行效果仍需用户验收。
