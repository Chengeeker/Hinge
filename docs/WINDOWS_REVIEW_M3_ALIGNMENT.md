# Windows 对齐 Review 的 Material 3 视觉

候选：Windows 2.7.3.0。参照 Review 的 AppTheme、AppSectionCard、ReviewPreferenceTile 和导航主题；使用 WinUI 原生布局与文字呈现。

## 视觉对应

| Review 的规则 | Hinge Windows |
| --- | --- |
| 内容卡片：22 圆角、0.8 轻描边 | 首页内容卡片采用独立 HingeContentCardStyle；浅色使用 surfaceContainerLow，深色使用 Review 的 #1B1C20 |
| 设置分组：24 圆角、低强调表面 | HingeCardStyle 统一承担分组容器，使用 surfaceContainerLow、16 内边距 |
| 设置行：标题、说明分层 | 标题15、说明13；分组标题16并使用 primary；设置入口内部间距16/12，行高至少72 |
| 轻分隔线 | 独立语义画刷，outlineVariant 的30%透明度；设置首页使用0.5线宽 |
| 多角色色板 | 保留Hinge原主色和用户选择，Material tonalSpot生成真正独立的secondary/tertiary，neutral使用neutral变体 |
| 深色背景与导航 | 使用Review的 #111215 页面和 #16171B 导航表面，内容卡片相对页面抬亮 |
| 按钮状态层 | 填充、色调、描边按钮及设置行使用foreground的8%悬停、12%按下覆盖，保持基底色与文字清晰 |
| 可见焦点与清晰文字 | 保留原生Button语义、系统键盘焦点和ContentPresenter，不缩放或截图化文字 |

侧栏继续使用已经确认的Medium字重和原生SymbolIcon，不新增加粗轮廓；现有高对比度字典使用系统颜色。输入框继续使用WinUI原生编辑模板，使用较轻的表面及与主题一致的悬停、焦点颜色。对话框标题单独保留18字号。六组主题色及浅深模式均有对应资源。2.7.1进一步统一了创建/取消按钮与选择控件的手形光标；个性化、文件和日期/时间等选择控件使用一致的Harmony字体族、字号与布局舍入。简体中文待办日期列按年/月/日1.2:1:1分配，其他语言的长月份名称仍保留系统原生列宽。文本框、下拉项、日历选择器及弹窗按主题色角色着色；浅色输入表面使用surfaceContainerHigh，首页卡片改用surfaceContainerLow，不再铺纯白。

## 检查范围

- 84组正文/主色/次色/容器文字配对对比度均不低于4.5:1。
- 原生离线预览实际加载当前主题、首页与设置页，生成浅深两套截图；检查主要按钮的Normal/PointerOver/Pressed/Disabled状态和系统焦点配置。
- 预览同时覆盖紧凑与宽屏首页排版，示例设备和空传输记录为离线数据。没有启动Hinge业务进程、ADB、网络连接或操作手机。
- 当前只能据此确认这些公共样式与代表页面。尚未覆盖安装后的所有菜单、对话框、字体缩放和系统高对比度交互；图片播放器、传输与远控逻辑没有另行修改。
- 2.7.1原生离线探针在应用根窗口与主页/设置页整窗切换浅/深主题，确认整窗背景和内容表面同步变色；同时检查日期列、选择控件字体、生成对话框按钮手形光标及主题资源。深色弹窗单独截图外围透明区域在图片查看器显示为黑色，不代表应用窗口背景；整窗设置页截图用于验证背景。

实现位于 Themes/HingeM3.xaml、App.xaml、ThemeBrushes.cs 及首页/设置入口页。色板预先计算，无新增运行时依赖、模糊滤镜或每帧背景渲染。

Windows主线安装器/便携包2.7.1.0及Android ARM64 2.7.1+139已构建并核对版本、载荷完整性，Android正式签名与16KiB对齐通过。当前为本地候选，旧包保留，未推送或创建GitHub Release。仍需用户在安装后的实际显示环境确认字体清晰度和交互手感；离线渲染不等于目标电脑上的实机验收。

## 2.7.2启动修正

2.7.1日历选择器引用了当前SDK不存在的DefaultCalendarDatePickerStyle，应用启动刷新全局字体资源时抛出COMException，导致无窗口。删除无效BasedOn，保留原生隐式模板及M3 Setter后，隔离启动探针已通过同样的字体刷新、主题配置和首页导航。早期控件截图漏测这条资源刷新路径。2.7.2.0 Windows安装器/便携包与2.7.2+140 Android ARM64主包均重新构建、核验；探针在网络服务创建前退出，安装后的完整运行尚待确认。

## 2.7.3相册显示崩溃修正

新增的派生ComboBox在实际XAML页面首次布局时出现主题URI解析异常。恢复SDK原生ComboBox/ComboBoxItem，保留M3样式与字体；公共光标辅助对原生控件设置手形并响应禁用状态，不再为光标替换控件类型。弱引用表避免重复挂载和页面保留，投影属性不可用时退回系统光标。相册、文件管理、个性化的浅深主题显示、展开/选择/关闭及启用/禁用检查均通过，并复验初始化到首页；未连接设备或验收实机图片加载。Windows2.7.3.0 / Android2.7.3+141主线包重新构建并核验。
