# 无线 ADB 指令

Windows「设置 → 传输与连接 → 高级诊断 → Android 无线 ADB」的目标 IP、配对端口和连接端口默认展示，不再折叠。

在下方「ADB 指令」输入一条设备指令后点击运行，例如：

```text
adb shell getprop ro.product.model
shell dumpsys battery
adb logcat -d
adb pull "/sdcard/Download/example.txt" "D:\Downloads\example.txt"
```

- 使用已配对且当前连接的手机，运行状态显示固定的目标地址。无需输入设备编号，不接受覆盖 `-s`、`-P` 等全局选项。连接、配对和 ADB Server 管理仍通过对应连接入口执行。
- 保留输入的双引号与参数格式，直接启动内置 ADB，复用隔离的 5038 端口和已有主机密钥，不经过 Windows 命令解释器。
- 标准输出和错误输出实时显示并可选中复制。最多显示 64K 字符，额外输出继续读取但不再保存到界面；刷新限频且读取不占用界面线程。
- 指令最长 8192 字符，只支持一条命令，不支持交互输入；单次运行 60 秒后停止。可点击停止，离开设置页或退出应用也会停止本次进程。停止不会撤销手机已经执行的操作。
- 指令与输出不写入配置、历史或诊断日志。某条指令本身要求生成/下载的文件仍会按指令执行。

候选版本：Windows 2.6.0.0；Android 2.6.0+137 仅同步版本并按项目流程构建，手机端没有增加 ADB 指令界面。

离线验证覆盖参数规范化、固定设备与5038、拒绝切换目标/服务管理、输出截断、进程取消，以及既有无线ADB发现/重连回归。测试只创建本机临时输出进程，没有连接或操作手机；真实无线设备命令执行与安装后UI仍需验收。

正式构建和43项定向回归通过；Android ARM64主包签名、16KiB对齐及包版本核验通过，Windows便携包与安装器内嵌载荷一致。当前为本地候选，未安装或推送发布。
