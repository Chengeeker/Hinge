# 编码规范与安全基线

## 日志与隐私合规

生产模式下严禁将以下内容打印到日志文件或控制台：

- 文件的真实物理路径（非必要时采用相对路径或文件名）
- 传输文件的实际内容
- 剪贴板真实文本或图片内容
- 通知正文敏感信息
- 任何私钥、凭据或未加密的 Token

## 状态机优先架构

跨设备通信流程不得使用多个离散布尔变量表示同一业务状态。连接、传输、媒体和同步流程应使用明确的枚举状态，并集中处理状态迁移和断线回收。

## 错误处理模型

跨端工具请求使用统一的可序列化错误结构：

```json
{
  "code": "FILE_DISK_FULL",
  "message": "Target storage has insufficient disk space.",
  "severity": "ERROR",
  "retryable": false
}
```

## 依赖准入

新增功能前必须依次确认：

1. 当前工程是否已有实现。
2. 操作系统原生 API 是否能够解决。
3. 现有依赖是否能够解决。
4. 新依赖的许可证、体积、维护状态和攻击面是否可接受。
