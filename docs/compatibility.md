## 验收原则

1. Android 前台服务只能降低系统回收概率，不能绕过厂商电池策略。
2. 真实设备需要分别验证锁屏、切后台、切换 Wi-Fi、IP 地址变化和进程被系统回收后的重连。
3. Windows 端需要分别验证防火墙、多个网卡、公共网络配置和默认文件关联应用。
