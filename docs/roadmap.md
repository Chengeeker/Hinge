# 产品路线图

路线图按用户可感知的产品价值排序，不以历史 Phase 编号替代验收结果。

## 当前版本：v1.0.17-dev.1

- 双端设备发现、会话和文件工作流已形成可构建的垂直切片；
- Windows 文件管理、相册分页和系统默认媒体打开已纳入发布包；
- Android 工作区、Monet 主题和保活设置入口已纳入发布包；
- 当前重点从“继续堆入口”转为真实设备稳定性、性能和安全边界验证。

## 下一优先级：连接和数据可靠性

1. 用真实 Android 与 Windows 双进程测试覆盖断网、锁屏、切 Wi-Fi、IPv4 变化和多网卡；
2. 完成完整身份握手、TrustStore 强制校验、会话密钥和未授权连接拒绝；
3. 为传输补充严格的 offset、chunk index、长度、取消、恢复和磁盘空间错误处理；
4. 将日志、超时、重试和错误提示统一成可诊断的连接报告。

## 第二优先级：大型内容和性能

1. 继续优化微信/QQ、文档和相册的分页索引、缩略图缓存和并发预算；
2. 用内存、CPU、无线吞吐和 UI 帧率指标调度请求，不以盲目增加线程数替代性能设计；
3. 增加真实大文件、重复文件名、Unicode 路径和默认应用不可用的测试。

## 第三优先级：原生能力补齐

- Android 原生屏幕采集、编码，Windows 原生解码和独立投屏窗口；
- Android 通知读取/转发和 Windows 通知展示；
- Windows OCR 与 Android OCR 的真实 Provider；
- 完整的后台保活引导和不同厂商设置路径维护。

## 暂不做的事情

- 不在没有真实协议和性能证据时继续包装投屏、通知回复或 OCR 的 UI；
- 不通过无上限并发来掩盖网络、服务端分页或 UI 线程阻塞；
- 不把回环测试结果写成所有真机均已验证。
